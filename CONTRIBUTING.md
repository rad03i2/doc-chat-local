# Contributing / المساهمة

Contributions are welcome. Open an issue for significant behavioral changes. Keep the tool local-first: do not add mandatory cloud services, telemetry, credentials, or network calls. Add tests for behavior changes and run `python -m compileall -q src` and `pytest -q` before submitting a pull request. Keep public APIs documented and preserve Python 3.10+ compatibility.

المساهمات مرحب بها. افتح Issue قبل التغييرات السلوكية الكبيرة. حافظ على مبدأ التشغيل المحلي، ولا تضف خدمات سحابية إلزامية أو تتبعًا أو بيانات اعتماد أو اتصالات شبكة. أضف اختبارات للتغييرات وشغّل `compileall` و`pytest` قبل إرسال Pull Request.
